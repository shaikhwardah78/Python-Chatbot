# 🤖 My First Python Chatbot

This is my first Python project! A simple rule-based chatbot.

## What I Learned
- Python functions (`def`)
- If-else statements
- User input with `input()`
- While loops

## How to Run
1. Make sure you have Python installed
2. Run: `python chatbot.py`
3. Start chatting!
